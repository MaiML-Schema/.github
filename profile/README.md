# MaiML-Schema

🌐 Language: **日本語** | [English](README_en.md)


**MaiML（Measurement Analysis Instrument Markup Language）** のXML Schema（XSD）の開発・保守を行うGitHub Organizationです。

MaiML-Schemaでは、新しいスキーマバージョンの設計、検証、互換性評価、レビューなど、正式リリースに向けたスキーマ開発を行っています。

---

## MaiML-Schemaとは

MaiML-Schemaは、MaiMLのXML Schemaを開発・管理するためのOrganizationです。

主な活動内容は次のとおりです。

- XML Schema（XSD）の設計・開発
- スキーマのバージョン管理
- スキーマの検証・互換性評価
- スキーマドキュメントの整備
- リリース前のレビュー・品質確認

十分な検証を経たスキーマは、正式版として[リリース](https://www.maiml.org/)されます。

---

## 開発方針

このOrganizationで管理されるスキーマは開発中のものを含みます。

そのため、

- スキーマ構造や定義が変更される場合があります。
- 後方互換性は検証・レビューを経て評価されます。
- 正式版として公開されたスキーマのみを安定版として扱います。

## コントリビューション

MaiML Schemaの品質向上に向けたご協力を歓迎します。

例えば、次のような貢献をお待ちしています。
